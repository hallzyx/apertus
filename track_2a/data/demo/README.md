# Official demo booklet

`votation-2026-03-08-fr.pdf` is the unchanged official Swiss voting booklet
for 8 March 2026, published by the Federal Chancellery. Its 72-page layout includes
French and German source text. This small 1.19 MB demo asset avoids requiring the
official server to be reachable from a GPU host. It contains no benchmark labels.
